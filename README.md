# Hotel-Booking-Cancellation-Analysis
  จัดทำขึ้นเพื่อวิเคราะห์ข้อมูลการจองโรงแรมและศึกษาความสัมพันธ์ระหว่างปัจจัยต่าง ๆ กับสถานะการยกเลิกการจอง โดยมีคำถามหลักคือ ปัจจัยด้านการจองและข้อมูลของลูกค้ามีความสัมพันธ์กับการยกเลิกการจองโรงแรมหรือไม่ จากนั้นนำผลการวิเคราะห์มาแสดงผลในรูปแบบ Interactive Data Visualization ผ่านเว็บไซต์ โดยพัฒนาเว็บไซต์ด้วย D3.js และ Chart.js เพื่อช่วยให้ผู้ใช้งานสามารถสำรวจและทำความเข้าใจข้อมูลได้ง่ายขึ้น
